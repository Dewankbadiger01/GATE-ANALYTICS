## ✦ The idea

**GATE preparation deserves more than another question bank.**

AI GATE Mentor is a learning platform being developed to make GATE Computer Science preparation more structured, interactive and intelligent.

It brings together previous-year question discovery, subject-wise learning, AI-assisted explanations and preparation analytics in one workspace.

The vision is simple: help students move beyond memorizing answers and develop a deeper understanding of concepts.

## ✦ Under the hood

The platform follows a modular full-stack architecture.

**Frontend → Backend API → Database / AI Service**

- React manages the student-facing experience.
- Express handles application requests.
- Prisma manages structured academic data.
- PostgreSQL stores subjects, topics, questions, options and answers.
- Gemini provides the planned AI explanation capability.

The architecture keeps AI integration and academic data management separate.

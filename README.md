

AI GATE Mentor

---

## ✦ The Idea

GATE preparation deserves more than just another standard question bank.

**AI GATE Mentor** is an intelligent learning platform designed to make GATE Computer Science preparation more structured, interactive, and data-driven. It integrates previous-year question (PYQ) discovery, subject-wise learning paths, AI-assisted explanations, and performance tracking into a single, cohesive workspace.

The core vision is simple: help students move beyond rote memorization and develop a deeper, intuitive understanding of core computer science concepts.

## ✨ Key Features

* **Concept-Oriented Learning:** Focuses on the reasoning and mechanics behind solutions rather than just correct answers.
* **Structured Question Discovery:** Organizes preparation systematically around the official GATE CS syllabus.
* **AI-Assisted Explanations:** Powered by Google Gemini to provide contextual, adaptive learning assistance.
* **Preparation Insights:** Tracks problem-solving habits to help identify strengths and knowledge gaps.

## 🏗️ Under the Hood

The platform follows a modular, full-stack architecture keeping academic data management cleanly separated from AI orchestration:

```text
[ React Frontend ] ---> [ Express Backend API ] ---> [ Prisma ORM ] ---> [ PostgreSQL Database ]
                                                         |
                                                         +---> [ Google Gemini AI Service ]

```

* **Frontend:** Manages the student-facing interactive workspace.
* **Backend:** Handles application logic, routing, and REST endpoints.
* **Database & ORM:** Structures subjects, topics, questions, options, and user data efficiently.
